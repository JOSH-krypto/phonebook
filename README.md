# Full Stack Open (Parts 0–4)

A collection of my solutions and projects for **Parts 0–4** of the **Full Stack Open** course by the **University of Helsinki**.

This repository documents my journey learning modern full-stack web development using JavaScript, React, Node.js, Express, and MongoDB. Each part builds upon the previous one, introducing new concepts through hands-on exercises and real-world applications.

---

## 📚 Course Overview

Full Stack Open is a practical web development course that focuses on building modern single-page applications and backend services using JavaScript.

By the end of Part 4, I have learned how to:

* Build responsive user interfaces with React.
* Manage application state using React Hooks.
* Fetch and manipulate data from REST APIs.
* Create backend APIs using Node.js and Express.
* Store and retrieve data with MongoDB and Mongoose.
* Structure backend applications following MVC principles.
* Implement user authentication using JSON Web Tokens (JWT).
* Secure passwords with bcrypt.
* Write backend unit and integration tests using Jest and Supertest.
* Handle errors and middleware effectively.
* Build complete full-stack applications.

## 🚀 Running a Project

Clone the repository:

```bash
git clone https://github.com/JOSH-krypto/Full-stack-course/fullstackopen.git
```

Navigate to a project:

```bash
cd part4/bloglist
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

For backend projects:

```bash
npm start
```

Run tests:

```bash
npm test
```
