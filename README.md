# Phonebook App

A simple full‑stack phonebook application built with **React (Vite)** on the frontend and **Express.js** on the backend.

------------------------------------------------------------------------------------------------------

##  Live Demo
- **Frontend:** [https://phonebook-1-r7uo.onrender.com](https://phonebook-1-r7uo.onrender.com)  
- **Backend API:** [https://phonebook-yyk9.onrender.com/api/persons](https://phonebook-yyk9.onrender.com/api/persons)

------------------------------------------------------------------------------------------------------

##  Features
- Add new contacts with name and phone number
- Delete existing contacts
- View all contacts
- Backend logging with **morgan**
- CORS enabled for cross‑origin requests
- Frontend served via Vite build

------------------------------------------------------------------------------------------------------

##  Technologies
- React + Vite
- Express.js
- Node.js
- Render (deployment)
- Morgan (logging)
- CORS

-------------------------------------------------------------------------------------------------------
## 🚀 How to run locally
- Clone Repo  
  git clone https://github.com/JOSH-krypto/phonebook.git  
  cd phonebook  

- Install backend dependencies  
  cd backend  
  npm install  

- Start backend server  
  npm run dev  

- Install frontend dependencies  
  cd ../frontend  
  npm install  

- Run frontend  
  npm run dev  

- Build frontend for production  
  npm run build  

- Serve static files from the backend  
  cp -r dist ../backend
